# 嗦蹄子

一个轻松的群互动插件：@群友「嗦」TA 的蹄子，并统计每个人的嗦人/被嗦战绩。

## 功能

- **嗦人**：`嗦 @群友` —— 嗦一下对方，回复中附带对方 QQ 头像和被嗦总次数。
- **战绩查询**：`嗦啼战绩 @群友`（或 `嗦啼战绩` 查自己）—— 展示嗦人次数（附趣味评价）与被嗦次数（附称号）。
- **数据持久化**：战绩数据保存在 `data/plugin_data/嗦嗦群友/suo_list.json`，原子写入 + 脏数据定时落盘，重启不丢。
- **可自定义**：命令前缀、两个命令的触发词、空前缀开关、自动保存间隔均可在插件配置里改。

## 指令

| 指令 | 说明 |
| --- | --- |
| `嗦 @群友` | 嗦一下被 @ 的群友 |
| `嗦啼战绩` | 查询自己的嗦啼战绩 |
| `嗦啼战绩 @群友` | 查询指定群友的战绩 |

默认前缀为 `.`，即实际输入 `.嗦 @群友`、`.嗦啼战绩`。开启「空前缀」后可不带前缀直接触发。

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 命令前缀 → prefix | list | `["."]` | 命令前缀列表，可配多个 |
| 命令前缀 → allow_empty_prefix | bool | false | 开启后可不带前缀直接触发命令 |
| 命令名称 → suo_command | string | `嗦` | 嗦命令触发词 |
| 命令名称 → stats_command | string | `嗦啼战绩` | 战绩命令触发词 |
| auto_save_interval | int | 60 | 有数据变更时自动写盘间隔（秒） |

## 安装

- **插件市场**：搜索「嗦蹄子」安装。
- **本地安装**：在 AstrBot 管理面板「插件」页上传本插件 zip 包。

## 升级（覆盖安装）

AstrBot 上传 zip 不会覆盖同名目录，升级时请：

1. 在面板卸载本插件（**不要勾选**「删除配置」「删除数据」，战绩不会丢）；
2. 再上传新版 zip。

## 数据说明

- 战绩数据：`data/plugin_data/astrbot_plugin_suosuo/suo_list.json`，结构为 `{QQ号: {"suo": 嗦人次数, "suoed": 被嗦次数}}`。
- 删除该文件即可重置全部战绩。

## 环境要求

- AstrBot v4+
- 无额外第三方依赖
