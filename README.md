# 嗦蹄子

@群友「嗦」TA 的蹄子，并记战绩。

## 指令

| 指令 | 说明 |
| --- | --- |
| `.嗦 @群友` | 嗦一下被 @ 的群友 |
| `.嗦蹄战绩` | 查自己的战绩 |
| `.嗦蹄战绩 @群友` | 查某个群友的战绩 |

触发方式两种都能用：

- **带前缀**：`.嗦 @某人`
- **裸命令**：`嗦 @某人`、`嗦蹄战绩`

> 裸命令能用的原因：AstrBot 会先把你消息开头的全局唤醒词（wake_prefix，默认含 `.`）去掉，
> 再交给插件。所以你敲 `.嗦`，插件收到的是 `嗦`。**不用重复配前缀**。

群里日常聊天（「嗦粉」「嗦一口」「嗦螺蛳粉」）不会被误触发——命令名后面必须跟空白或 @。

## 战绩显示

```
嗦蹄战绩　称号：嗦蹄小手子
嗦人：3 次　被嗦：9 次
评价：这里常年湿润　排行：本群第 1 名被嗦
```

「排行」是本群按被嗦次数的名次，同分同名次。

## 关于「啼」

v1.0 的命令默认值写的是「嗦啼战绩」（啼），但插件名是「嗦蹄子」（蹄）。
你在配置页存下的值优先于默认值，所以旧配置里那个错字会一直生效。
新版已在启动时自动纠正，你不用手动改。

## 配置

插件配置页可改：

| 配置项 | 说明 |
| --- | --- |
| 命令前缀 → prefix | 命令前缀列表，如 `["."]`。留空会被忽略 |
| 命令名称 → suo_command / stats_command | 两条命令的触发词 |
| 档位 → comment_tiers | 评价档位，按嗦人次数取命中数值的最高档 |
| 档位 → title_tiers | 称号档位，按被嗦次数取命中数值的最高档 |
| 话术 → stats_header / stats_suo / stats_suoed | 战绩页的几行文案 |
| 话术 → avatar_template | 头像地址模板，`{qq}` 会被替换。**必须以 http:// 或 https:// 开头**，留空则不显示头像 |

档位里 `min` 填 0 的那档是兜底，次数为 0 也有话说。

## 数据

| 文件 | 说明 |
| --- | --- |
| `data/plugin_data/astrbot_plugin_suosuo/suo_list_by_group.json` | 按群隔离的战绩，键是 `群号:QQ` |
| `data/plugin_data/astrbot_plugin_suosuo/suo_list.json` | **v1.0 的老存档**，只读继承，不会被改写 |

**升级不会丢战绩。** 某个 QQ 第一次在某个群里互动时，会把ta在 v1.0 老存档里的数字
当作该群的起始值，之后该群的新数据才写进新文件。老存档原封不动地留着，
删掉新目录就能完全回到 v1.0。

战绩**按群隔离**：A 群和 B 群互不影响。

## 安装

AstrBot 管理面板「插件」页上传 zip 包。覆盖安装需先卸载旧的（**不要勾选**「删除数据」）。

## 装完先验这几条

- `.嗦 @某人` → 应该回一条，**不是两条**（回两条是 v1.0 的已知问题，v2 已修）
- 随便聊一句「今天吃什么」→ 不应该有任何反应
- 群里发「嗦粉」→ 不应该触发
- `.嗦蹄战绩` → 数字应该和 v1.0 时期对得上
